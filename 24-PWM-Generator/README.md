# PWM Generator

## Project 24 – Vivado RTL Design Roadmap

This project implements a Pulse Width Modulation (PWM) generator using Verilog HDL.

The PWM output is generated by continuously comparing a 3-bit counter with a configurable duty-cycle input.

```text
Counter + Duty Cycle Comparison → PWM Output
```

## Features

- 3-bit free-running counter
- 8-count PWM period
- Configurable 4-bit duty-cycle input
- Supports duty-cycle values from 0 to 8
- Generates 0%, 25%, 50%, 75%, and 100% PWM outputs
- Uses sequential and combinational RTL logic
- Verified using a Verilog testbench and behavioral simulation

## PWM Principle

The PWM output follows this rule:

```text
counter < duty_cycle
        ↓
     pwm_out = 1

counter >= duty_cycle
        ↓
     pwm_out = 0
```

The counter repeatedly counts:

```text
0 → 1 → 2 → 3 → 4 → 5 → 6 → 7 → 0 → ...
```

One complete journey from `0` to `7` forms one PWM period.

## Counter Design

A 3-bit counter is used:

```verilog
reg [2:0] counter;
```

It can represent eight values:

```text
000 = 0
001 = 1
010 = 2
011 = 3
100 = 4
101 = 5
110 = 6
111 = 7
```

After reaching `7`, the counter automatically wraps back to `0`.

## Duty Cycle Operation

| duty_cycle | ON Counts | Duty Cycle |
|---:|---:|---:|
| 0 | 0 out of 8 | 0% |
| 2 | 2 out of 8 | 25% |
| 4 | 4 out of 8 | 50% |
| 6 | 6 out of 8 | 75% |
| 8 | 8 out of 8 | 100% |

For example, when:

```text
duty_cycle = 4
```

the output pattern is:

```text
Counter:  0  1  2  3  4  5  6  7
PWM:      1  1  1  1  0  0  0  0
```

Therefore:

```text
HIGH time = 4 counts
LOW time  = 4 counts
Duty cycle = 50%
```

## LED Brightness Concept

The PWM signal can be used to control LED brightness.

```text
Short HIGH pulse → Lower average power → Dim LED

Long HIGH pulse  → Higher average power → Bright LED
```

The LED is still switched fully ON and fully OFF. If the switching is fast enough, the human eye perceives the average brightness.

```text
Low duty cycle  → Dim
50% duty cycle  → Medium brightness
High duty cycle → Bright
100% duty cycle → Maximum brightness
```

## RTL Structure

The design contains two main blocks.

### Sequential Counter Logic

```verilog
always @(posedge clk) begin
    if (reset)
        counter <= 0;
    else
        counter <= counter + 1;
end
```

This block updates the counter on every positive clock edge.

### Combinational PWM Logic

```verilog
always @(*) begin
    if (counter < duty_cycle)
        pwm_out = 1;
    else
        pwm_out = 0;
end
```

This block continuously compares the counter with the duty-cycle input.

## Simulation Test

The testbench verifies:

```text
0% → 25% → 50% → 75% → 100%
```

Each duty-cycle value is applied for one complete PWM period.

With a 10 ns clock period and eight counter values:

```text
PWM period = 8 × 10 ns
           = 80 ns
```
