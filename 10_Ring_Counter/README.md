# Ring Counter

## Description
A 4-bit Ring Counter implemented using Verilog HDL.

A single logic '1' circulates through the register on every positive clock edge.

## Sequence

0001 → 0010 → 0100 → 1000 → 0001

## Inputs
- clk
- rst

## Output
- q[3:0]
