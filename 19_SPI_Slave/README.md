# SPI Slave (Serial Peripheral Interface)

## Description

This project implements an **SPI Slave Receiver** using Verilog HDL.

The SPI Slave receives serial data from an SPI Master through the **MOSI (Master Out Slave In)** line. Data is sampled on the rising edge of the SPI clock (`SCLK`), shifted into an internal register, and converted into an 8-bit parallel output after receiving all bits.

---

## Features

- 8-bit SPI Slave Receiver
- MSB-First Data Reception
- Shift Register Based Design
- Bit Counter
- Chip Select (CS) Support
- Done Signal Generation
- Synthesizable RTL Design

## Block Diagram

```
                 +---------------------------+
                 |         SPI Slave         |
                 |                           |
MOSI ----------->|                           |
SCLK ----------->|  Shift Register           |
CS ------------->|  Bit Counter              |
                 |                           |
                 +---------------------------+
                      │
                      │
                 rx_data[7:0]
                      │
                    done
```

---

## Working Principle

1. Wait until **CS becomes LOW**.
2. On every rising edge of **SCLK**, sample one bit from **MOSI**.
3. Shift the received bit into the internal shift register.
4. Count each received bit.
5. After 8 bits are received, copy the shift register to `rx_data`.
6. Assert the `done` signal to indicate successful reception.
7. Wait for the next SPI transaction.
