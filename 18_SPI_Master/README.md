# SPI Master (Serial Peripheral Interface)

## Description

This project implements an **SPI Master Transmitter** using Verilog HDL.

The SPI Master transmits 8-bit serial data to an SPI Slave using the MOSI line. The design uses a Finite State Machine (FSM), shift register, clock divider, and bit counter to control the communication process.

---

## Features

- 8-bit Serial Transmission
- SPI Master Implementation
- FSM-Based Control
- Shift Register
- Clock Divider
- Bit Counter
- Chip Select (CS)
- Transmission Complete (Done) Signal
- Synthesizable RTL Design

## FSM Flow

```
           +------+
           | IDLE |
           +------+
               |
               v
           +------+
           | LOAD |
           +------+
               |
               v
          +---------+
          | SHIFT   |
          +---------+
               |
               v
           +------+
           | DONE |
           +------+
               |
               +-------> IDLE
```

---

## Working Principle

1. Wait for the **Start** signal.
2. Load the input byte into the shift register.
3. Pull **CS Low** to select the slave.
4. Generate the SPI clock using the clock divider.
5. Transmit one bit per SPI clock on the MOSI line.
6. Count the transmitted bits.
7. After 8 bits, raise the **Done** signal.
8. Release **CS High** and return to the IDLE state.
