# Vivado RTL Designs

This repository contains RTL design projects implemented in Verilog and verified using Xilinx Vivado.

## Projects

1. 4:1 Multiplexer
2. Ring Counter
3. Johnson Counter
4. Universal Shift Register
5. Sequence Detector (1011)

## Tools Used
- Verilog HDL
- Xilinx Vivado
- Simulation Testbenches
