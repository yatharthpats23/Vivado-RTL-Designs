# 🚀 Vivado RTL Designs

A collection of Verilog HDL, RTL Design and FPGA projects developed using Xilinx Vivado.

---

## 📌 About

This repository contains beginner to intermediate RTL Design projects implemented in Verilog HDL.

The objective of this repository is to strengthen Digital Design, RTL Design and FPGA development skills through practical implementation.

---

## 🛠 Tools Used

- Verilog HDL
- Xilinx Vivado
- Behavioral Simulation
- RTL Schematic
- Testbench Verification
